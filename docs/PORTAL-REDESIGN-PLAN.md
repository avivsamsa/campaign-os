# תוכנית: התאמת הפורטל-ווב למבנה האפליקציה

מטרה: פורטל הלקוח בווב (`app/[slug]/`) יראה במבנה UI/UX כמו האפליקציה (לא בהכרח אנימציות — המבנה).

## סטטוס
1. ✅ **דשבורד בית** — KPIs (לידים/חדשים/מכירות/רווח) + "קמפיינים פעילים" (כרטיסים עם אייקון, פיל "N חדשים", בר התקדמות). טאב "בית" בניווט. (`app/[slug]/page.tsx`, `PortalDashboard.tsx`, `lib/portal-dashboard.ts`)
2. ⬜ **רשימת לידים** — לעצב כמו האפליקציה: צ׳יפ סטטוס צבעוני, כפתורי חיוג/וואטסאפ, חיפוש + פילטרי סטטוס (chips), שורות RTL (שם ימין, סטטוס+כפתורים שמאל). קובץ: `app/[slug]/leads/PortalLeadsManager.tsx`.
3. ⬜ **פרטי ליד** — שינוי סטטוס inline (כולל רכישה/סכום + לא-רלוונטי/סיבה + סטטוס מותאם), יומן פעילות (note/status/purchase). קובץ: `LeadDrawer.tsx` / `PortalNotesPanel.tsx`.
4. ⬜ **התראות** — מיזוג לידים חדשים + עדכוני סוכנות (`portal_messages`), סימון נקרא/לא-נקרא, כמו באפליקציה.
5. ⬜ **אתר — תנאים/פרטיות + נגישות** (חוק ישראלי, נפרד מאפל):
   - קישורים גלויים לתנאים/פרטיות בעמוד ההתחברות של הפורטל.
   - הצהרת נגישות + התאמה ל-WCAG 2.0 AA / ת"י 5568 (ניגודיות, פוקוס, aria, ניווט מקלדת).

## עקרונות
- אותם טוקנים קיימים ב-`app/globals.css` (wine/ink) — כבר תואם לאפליקציה.
- אייקוני SVG (לא אמוג׳י), מספרים tabular, RTL נכון, מצב בהיר/כהה.
