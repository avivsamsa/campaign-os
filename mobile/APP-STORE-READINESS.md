## 🚀 Runbook הגשה (הצעדים שלך במחשב)

> דורש את חשבון ה-Apple Developer שלך. הרץ בתיקיית `mobile/`.

```bash
cd mobile
npm i -g eas-cli            # פעם אחת
eas login                  # עם חשבון ה-Expo שלך
eas init                   # מקשר פרויקט (יוסיף projectId ל-app.json)
eas build -p ios --profile production   # בונה בענן (~15 דק')
eas submit -p ios --latest              # מעלה ל-App Store Connect (ישאל Apple ID/Team)
```

לאחר ההעלאה — ב-App Store Connect: למלא App Privacy (Contact Info, ללא Tracking), חשבון בודק `demo`/`demo2026`, Review Notes (סעיף 3 למטה), Support/Privacy URL, צילומי מסך 6.7″, ולהגיש לביקורת.

## הגדרות טכניות שכבר תוקנו ב-`app.json`

- ✅ `ITSAppUsesNonExemptEncryption: false` — עונה מראש על שאלת **Export Compliance** (אנחנו רק HTTPS סטנדרטי). חוסך עיכוב בכל build.
- ✅ `supportsTablet: false` — **iPhone-only**. מונע דחיות על פריסת iPad (האפליקציה תרוץ על iPad במצב תאימות). אם בעתיד נרצה iPad — נתאים פריסות ונחזיר.
- ✅ `buildNumber: "1"`, `version: "1.0.0"`.
- ✅ `userInterfaceStyle: "automatic"` — תואם למצב בהיר/כהה החדש.
- ✅ Privacy Manifest (`PrivacyInfo.xcprivacy`) — Expo SDK 54 מייצר אוטומטית עבור מודולי Expo (SecureStore וכו׳) ב-EAS build.

## מה שאתה ממלא ב-App Store Connect (⚠️ ידני)

### App Privacy (תוויות פרטיות — "Nutrition Labels")
הצהר בכנות. עבורנו:
- **Contact Info** → שם, טלפון, אימייל (של הלידים, המנוהלים עבור הלקוח). מקושר למשתמש: כן. Tracking: **לא**.
- **User Content** / **Identifiers** — טוקן התחברות (מזהה חשבון). Tracking: **לא**.
- **Data used to track you: None** — אנחנו לא עוקבים, אין SDK פרסומי, אין IDFA.
> אם תסמן "No data collected" זה יהיה **לא נכון** (יש שם/טלפון) → דחייה. הצהר Contact Info כמו למעלה.

### App Review Information
- Sign-in required: **Yes** → slug `demo`, password `demo2026`.
- Notes: הטקסט מסעיף 3 למעלה (חברת שיווק B2B, אין תשלום, חשבונות מסופקים ע״י הסוכנות).
- Contact: השם, טלפון ואימייל שלך.

### Metadata
- **Support URL** (חובה): `https://ppc.avivsamsa.co.il` (או דף תמיכה ייעודי).
- **Privacy Policy URL** (חובה): `https://ppc.avivsamsa.co.il/privacy`.
- **Age Rating**: 4+ (אין תוכן רגיש).
- **Category**: Business (ראשי) / Productivity (משני).
- **Screenshots**: 6.7″ (iPhone 15/16 Pro Max) חובה. צלם: התחברות, דשבורד, רשימת לידים, פרטי ליד, התראות. (מצב כהה או בהיר — עקבי.)
- **Description / Keywords**: תיאור אמיתי של פורטל ניהול לידים.
